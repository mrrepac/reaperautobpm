# TempoCNN Engine Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Essentia-based BPM engine with a TempoCNN (`deeptemp_k16`) engine converted to ONNX, keeping the existing Lua/PowerShell contract intact.

**Architecture:** A one-time offline conversion (Python 3.11 + TensorFlow venv) turns the published Keras weights into `deeptemp_k16.onnx`. A separate, TensorFlow-free runtime engine (Python 3.14 venv: `librosa` + `onnxruntime`, vendoring tempo-cnn's own feature-extraction code) is packaged with PyInstaller into `tempocnn_engine.exe`, which replaces the Essentia binary behind the same `launch_*.ps1`/`run_*.ps1` → result-file contract the Lua script already polls.

**Tech Stack:** Python 3.11 (conversion only, TensorFlow 2.17.0, tf2onnx), Python 3.14 (runtime engine: librosa, onnxruntime, numpy), PyInstaller, PowerShell 5 (`launch_engine.ps1`/`run_engine.ps1`), Lua (ReaScript).

## Global Constraints

- Repository is **not** a git repository (confirmed: `Is a git repository: false`). No `git add`/`git commit` steps in this plan — files are just saved to disk.
- Model: `deeptemp_k16` (per `docs/superpowers/specs/2026-08-18-tempocnn-engine-design.md`).
- Output contract from the engine executable: prints to **stdout only** —
  ```
  bpm: <float>
  confidence: <float 0-1>
  ```
  on success, exit code `0`. On failure: non-zero exit code, human-readable error text on stdout/stderr. This mirrors exactly how `essentia_streaming_rhythmextractor_multifeature.exe` is invoked today — engine gets **one positional argument** (audio path) and nothing else; the result-file writing and `__ENGINE_EXIT__=N` marker stay the PowerShell runner's job (`run_engine.ps1`), not the engine's.
- Lua/PowerShell timeout budget stays `ANALYSIS_TIMEOUT_MS = 180000` — do not change.
- `engine/` must end up containing exactly: `tempocnn_engine.exe`, `deeptemp_k16.onnx`, `launch_engine.ps1`, `run_engine.ps1`, `src/tempocnn_engine.py` (source, for reproducibility — mirrors the fact that the `.exe` itself is a build artifact, same as Essentia's was, but this one we authored so its source belongs in the repo). No leftover `essentia_*` files.
- AGPLv3 attribution for `tempo-cnn` (Hendrik Schreiber) must appear in `THIRD_PARTY_NOTICES.md` and as a header comment in `engine/src/tempocnn_engine.py` wherever code is vendored from `tempo-cnn`.
- No test audio may be copyrighted commercial material committed to the repo. Use synthetic click tracks generated by a small numpy script (see Task 2).

- [ ] **Step 1: Write the generator script**

`dev/test_audio/generate_fixtures.py`:
```python
"""Generates synthetic click-track WAV fixtures for engine testing.

No copyrighted material: pure numpy-synthesized clicks at known BPM.
Run with any Python 3.9+ that has numpy installed (no project venv needed).
"""
import struct
import wave
from pathlib import Path

import numpy as np

SR = 22050
DURATION_S = 20.0
CLICK_MS = 15
BPMS = (90, 120, 140)

OUT_DIR = Path(__file__).parent


def make_click_track(bpm: int) -> np.ndarray:
    total_samples = int(SR * DURATION_S)
    audio = np.zeros(total_samples, dtype=np.float64)
    beat_interval_s = 60.0 / bpm
    click_samples = int(SR * CLICK_MS / 1000)
    t = np.linspace(0, CLICK_MS / 1000, click_samples, endpoint=False)
    # 2 kHz tone burst with a fast exponential decay envelope
    click = np.sin(2 * np.pi * 2000 * t) * np.exp(-t * 60)

    beat_time = 0.0
    while beat_time < DURATION_S:
        start = int(beat_time * SR)
        end = min(start + click_samples, total_samples)
        audio[start:end] += click[: end - start]
        beat_time += beat_interval_s

    peak = np.max(np.abs(audio))
    if peak > 0:
        audio = audio / peak * 0.9
    return audio


def write_wav(path: Path, audio: np.ndarray) -> None:
    pcm16 = (audio * 32767.0).astype(np.int16)
    with wave.open(str(path), "wb") as f:
        f.setnchannels(1)
        f.setsampwidth(2)
        f.setframerate(SR)
        f.writeframes(pcm16.tobytes())


if __name__ == "__main__":
    for bpm in BPMS:
        out_path = OUT_DIR / f"click_{bpm}bpm.wav"
        write_wav(out_path, make_click_track(bpm))
        print(f"wrote {out_path} ({bpm} BPM)")
```

`dev/model_conversion/convert_to_onnx.py`:
```python
"""One-time conversion of tempo-cnn's deeptemp_k16 Keras model to ONNX.

Run with the Python 3.11 venv in this directory (see README.md).
Source model: https://github.com/hendriks73/tempo-cnn (AGPLv3).
"""
from pathlib import Path

import tf2onnx
import tensorflow as tf
from tempocnn.classifier import TempoClassifier

OUTPUT_PATH = Path(__file__).resolve().parents[2] / "engine" / "deeptemp_k16.onnx"


def main() -> None:
    classifier = TempoClassifier(model_name="deeptemp_k16")
    keras_model = classifier.model
    print("Loaded Keras model:")
    keras_model.summary()

    input_signature = [
        tf.TensorSpec(keras_model.input_shape, tf.float32, name="mel_windows")
    ]
    onnx_model, _ = tf2onnx.convert.from_keras(
        keras_model, input_signature=input_signature, opset=13
    )

    OUTPUT_PATH.parent.mkdir(parents=True, exist_ok=True)
    with open(OUTPUT_PATH, "wb") as f:
        f.write(onnx_model.SerializeToString())
    print(f"Wrote {OUTPUT_PATH} ({OUTPUT_PATH.stat().st_size} bytes)")


if __name__ == "__main__":
    main()
```

- [ ] **Step 1: Write the parity script**

`dev/model_conversion/verify_parity.py`:
```python
"""Verifies the ONNX conversion matches the original Keras model numerically.

Two checks:
1. Same input tensor -> Keras output vs ONNX output must be near-identical.
2. End-to-end BPM on synthetic fixtures must match between the original
   TempoClassifier (Keras) and onnxruntime, using tempo-cnn's own feature
   extraction for both (this script does NOT test the vendored engine copy
   of feature extraction -- that's Task 6).
"""
from pathlib import Path

import numpy as np
import onnxruntime as ort
from tempocnn.classifier import TempoClassifier, std_normalizer
from tempocnn.feature import read_features

REPO_ROOT = Path(__file__).resolve().parents[2]
ONNX_PATH = REPO_ROOT / "engine" / "deeptemp_k16.onnx"
FIXTURES = {
    "click_90bpm.wav": 90,
    "click_120bpm.wav": 120,
    "click_140bpm.wav": 140,
}


def main() -> None:
    classifier = TempoClassifier(model_name="deeptemp_k16")
    session = ort.InferenceSession(str(ONNX_PATH))
    input_name = session.get_inputs()[0].name

    any_failure = False

    # Check 1: raw tensor comparison on the first fixture's features.
    first_file = REPO_ROOT / "dev" / "test_audio" / next(iter(FIXTURES))
    data = read_features(str(first_file))
    norm_data = std_normalizer(data).astype(np.float32)

    keras_out = classifier.model.predict(norm_data, norm_data.shape[0])
    onnx_out = session.run(None, {input_name: norm_data})[0]

    max_abs_diff = float(np.max(np.abs(keras_out - onnx_out)))
    print(f"[tensor parity] max abs diff = {max_abs_diff:.6f}")
    if max_abs_diff > 1e-3:
        print("[tensor parity] FAIL: difference too large")
        any_failure = True
    else:
        print("[tensor parity] OK")

    # Check 2: end-to-end BPM comparison on all fixtures.
    for filename, expected_bpm in FIXTURES.items():
        path = REPO_ROOT / "dev" / "test_audio" / filename
        data = read_features(str(path))
        norm_data = std_normalizer(data).astype(np.float32)

        keras_bpm = classifier.estimate_tempo(data, interpolate=True)

        onnx_pred = session.run(None, {input_name: norm_data})[0]
        onnx_avg = np.average(onnx_pred, axis=0)
        onnx_index, _ = TempoClassifier.quad_interpol_argmax(onnx_avg)
        onnx_bpm = onnx_index + 30

        diff = abs(keras_bpm - onnx_bpm)
        print(
            f"[{filename}] keras={keras_bpm:.2f} onnx={onnx_bpm:.2f} "
            f"synth_bpm={expected_bpm} diff={diff:.4f}"
        )
        if diff > 0.5:
            print(f"[{filename}] FAIL: keras/onnx BPM diverge")
            any_failure = True

    if any_failure:
        print("RESULT: FAIL")
        raise SystemExit(1)
    print("RESULT: OK")


if __name__ == "__main__":
    main()
```

- [ ] **Step 2: Run it**

Run:
```bash
dev/model_conversion/.venv311/Scripts/python.exe dev/model_conversion/verify_parity.py
```
Expected: ends with `RESULT: OK`. If it fails, do not proceed to Task 5 — the ONNX file is not trustworthy yet. Likely causes: opset mismatch (try a different `opset` value in Task 3 Step 1) or a Keras layer `tf2onnx` doesn't support cleanly (check the printed model summary from Task 3 for unusual layer types).

- [ ] **Step 2: Write the engine script**

`engine/src/tempocnn_engine.py`:
```python
"""TempoCNN-based BPM engine for the "Detect beat BPM" REAPER action.

Feature extraction (read_features/_ensure_length/_add_zeros/_to_sliding_window)
and normalization (std_normalizer) below are ported from tempo-cnn
(https://github.com/hendriks73/tempo-cnn), Copyright Hendrik Schreiber,
licensed under AGPLv3 (https://www.gnu.org/licenses/agpl-3.0.html).
The model file deeptemp_k16.onnx is a format conversion of that project's
deeptemp_k16.h5, same license.

Usage: tempocnn_engine.exe <audio_path>
Prints "bpm: <float>" and "confidence: <float 0-1>" to stdout on success
(exit 0). On failure, prints an error message and exits non-zero.
"""
import sys
from pathlib import Path

import numpy as np
import librosa
import onnxruntime as ort

SR = 11025
N_FFT = 1024
HOP_LENGTH = 512
N_MELS = 40
FMIN = 20
FMAX = 5000
WINDOW_FRAMES = 256
WINDOW_HOP = 128
BPM_OFFSET = 30


def read_features(path: str) -> np.ndarray:
    y, _ = librosa.load(path, sr=SR)
    data = librosa.feature.melspectrogram(
        y=y, sr=SR, n_fft=N_FFT, hop_length=HOP_LENGTH,
        power=1, n_mels=N_MELS, fmin=FMIN, fmax=FMAX,
    )
    data = np.reshape(data, (1, data.shape[0], data.shape[1], 1))
    if data.shape[2] < WINDOW_FRAMES:
        data = _ensure_length(data, WINDOW_FRAMES)
    return _to_sliding_window(data, WINDOW_FRAMES, WINDOW_HOP)


def _ensure_length(data: np.ndarray, length: int) -> np.ndarray:
    padded = np.zeros((1, data.shape[1], length, 1), dtype=data.dtype)
    padded[0, :, 0:data.shape[2], 0] = data[0, :, :, 0]
    return padded


def _to_sliding_window(data: np.ndarray, window_length: int, hop_length: int) -> np.ndarray:
    total_frames = data.shape[2]
    windows = []
    span = ((total_frames - window_length) // hop_length + 1) * hop_length
    for offset in range(0, span, hop_length):
        windows.append(np.copy(data[:, :, offset:window_length + offset, :]))
    return np.concatenate(windows, axis=0)


def std_normalizer(data: np.ndarray) -> np.ndarray:
    data = data.astype(np.float64)
    mean = np.mean(data)
    std = np.std(data)
    if std != 0.0:
        data = (data - mean) / std
    return data.astype(np.float32)


def quad_interpol_argmax(y: np.ndarray) -> tuple[float, float]:
    x = int(np.argmax(y))
    if x == 0 or x == y.shape[0] - 1:
        return float(x), float(y[x])
    z = np.polyfit([x - 1, x, x + 1], [y[x - 1], y[x], y[x + 1]], 2)
    argmax = -z[1] / (2.0 * z[0])
    height = z[2] - (z[1] ** 2.0) / (4.0 * z[0])
    return float(argmax), float(height)


def model_path() -> Path:
    return Path(sys.argv[0]).resolve().parent / "deeptemp_k16.onnx"


def estimate(audio_path: str) -> tuple[float, float]:
    data = read_features(audio_path)
    norm_data = std_normalizer(data)

    session = ort.InferenceSession(str(model_path()))
    input_name = session.get_inputs()[0].name
    prediction = session.run(None, {input_name: norm_data})[0]

    averaged = np.average(prediction, axis=0)
    index, height = quad_interpol_argmax(averaged)
    bpm = index + BPM_OFFSET
    confidence = max(0.0, min(1.0, height))
    return bpm, confidence


def main() -> int:
    if len(sys.argv) != 2:
        print("usage: tempocnn_engine.exe <audio_path>", file=sys.stderr)
        return 2
    audio_path = sys.argv[1]
    if not Path(audio_path).is_file():
        print(f"audio file not found: {audio_path}", file=sys.stderr)
        return 1
    try:
        bpm, confidence = estimate(audio_path)
    except Exception as exc:  # noqa: BLE001 -- top-level CLI boundary
        print(f"tempocnn engine failed: {exc}", file=sys.stderr)
        return 1

    print(f"bpm: {bpm:.2f}")
    print(f"confidence: {confidence:.3f}")
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

No test in this step — Task 6 tests this script directly (as plain Python, before compiling), which is faster to iterate on than testing the compiled `.exe`.

- [ ] **Step 2: Write run_engine.ps1**

Same as `run_essentia.ps1`, with `__ESSENTIA_EXIT__` renamed to `__ENGINE_EXIT__` (two occurrences) and the error-path message text updated from "Essentia" to "engine":
```powershell
param(
    [Parameter(Mandatory = $true)][string]$EnginePath,
    [Parameter(Mandatory = $true)][string]$AudioPath,
    [Parameter(Mandatory = $true)][string]$ResultPath
)

$ErrorActionPreference = 'Stop'
$workingPath = "$ResultPath.running"
$exitCode = 125

try {
    $startInfo = New-Object System.Diagnostics.ProcessStartInfo
    $startInfo.FileName = $EnginePath
    $startInfo.Arguments = '"' + $AudioPath.Replace('"', '\"') + '"'
    $startInfo.UseShellExecute = $false
    $startInfo.CreateNoWindow = $true
    $startInfo.RedirectStandardOutput = $true
    $startInfo.RedirectStandardError = $true

    $process = New-Object System.Diagnostics.Process
    $process.StartInfo = $startInfo
    if (-not $process.Start()) {
        throw 'ProcessStartInfo could not start the engine.'
    }
    $stdoutTask = $process.StandardOutput.ReadToEndAsync()
    $stderrTask = $process.StandardError.ReadToEndAsync()

    if (-not $process.WaitForExit(180000)) {
        $process.Kill()
        $process.WaitForExit()
        $exitCode = 124
    }
    else {
        $exitCode = [int]$process.ExitCode
    }

    $stdout = $stdoutTask.GetAwaiter().GetResult()
    $stderr = $stderrTask.GetAwaiter().GetResult()
    $content = $stdout + $stderr + "`r`n__ENGINE_EXIT__=$exitCode`r`n"
}
catch {
    $content = "Engine runner error: $($_.Exception.Message)`r`n__ENGINE_EXIT__=125`r`n"
}

[System.IO.File]::WriteAllText($workingPath, $content, [System.Text.Encoding]::UTF8)
Move-Item -LiteralPath $workingPath -Destination $ResultPath -Force
```
